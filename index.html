How We Fixed the 3 Issues

1. Smart Text Splitting
  • Splits PDFs into exact 4,000-token slices (`tiktoken`).
  • Caches system prompts to save up to 70% on fees.
2. No LangChain Bloat
  • Uses direct Python API calls instead of heavy frameworks.
  • Forces strict JSON formatting via Pydantic v2.
3. Smart Security Routing
  • Secret docs go direct to private OpenAI/Azure servers.
  • Wraps PDF text in `<tender_doc>` tags to stop prompt hacks.
